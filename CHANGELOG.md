# Changelog

All notable changes will be documented here. RecoveryLens follows semantic versioning after its first public release.

## Unreleased

### Added

- Project charter, analytical principles, and seven-milestone roadmap.
- Official FEMA, NOAA, Census, and CDC/ATSDR source registry.
- Paginated OpenFEMA client with bounded queries and retry handling.
- County FIPS normalization and declaration aggregation.
- Transparent percentile-based recovery-equity scoring prototype.
- Automated linting, tests, and coverage reporting.
- Contribution, security, issue, and pull-request standards.
- Bounded Public Assistance funded-project extraction, normalization, and county aggregation.
